# Alight agent entry point

Read and follow `agent.md` in this directory before working on this project.
Read `context.txt` when present for the latest requested handoff, then read the
local `ALIGHT_PLAN.md` and `ALIGHT_BUILD.md` before implementation.

Never stage, commit, force-add, or push `ALIGHT_PLAN.md` or `ALIGHT_BUILD.md`.
Keep `context.txt` local as well. These paths are excluded by `.gitignore`.
The user's current instructions take precedence over these project instructions.
